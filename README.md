# TomoTrackAI 2.0

Proyecto de seguimiento de objetos para After Effects 2024 en macOS Monterey (Intel).

**Estado: en desarrollo. Todavía no hay un plugin nativo compilado y probado.**

Objetivo: selector de una región del video, tracking temporal y exportación de keyframes a objetos Null, preservando el metraje original.

Referencia técnica: [After Effects C++ SDK Guide](https://ae-plugins.docsforadobe.dev/). El SDK de Adobe, los binarios compilados y la compatibilidad real con AE 2024 requieren verificación; este repositorio no contiene componentes propietarios.

Se conservarán las versiones anteriores hasta validar un reemplazo.
